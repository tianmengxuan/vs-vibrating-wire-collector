### 新增: data_sensor 第三方同步表
**models.py** - DataSensor 模型(表9):
- sensor = UDID+CH+通道号
- sensorData1 = 频率Hz
- sensorData2 = 温度℃
- sensorData3 = 解算值
- batteryVolt = 电池电压
- sendTime = 接收时间
- dataSequence = 原始包ID
- CollectionTime = 采集时间

**crud.py** - batch_insert_data_sensor()
- 批量写入 data_sensor，独立事务

### 新增: 远程数据库同步 (101.37.18.32:3306)
**database/remote_sync.py** - RemoteSyncManager
- 独立连接远程 MySQL，惰性初始化
